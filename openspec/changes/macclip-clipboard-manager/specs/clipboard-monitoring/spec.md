# Spec Delta

## Purpose

Detect every new item the user copies on macOS and capture its content (text, rich text, images) while never recording sensitive or self-generated clipboard data.

## ADDED Requirements

### Requirement: Detect clipboard changes
The system SHALL detect a new clipboard item within 1 second of the user copying it, while running in the background.

#### Scenario: Text copied in another app
- **WHEN** the user copies text in any application
- **THEN** a new history entry containing that text exists within 1 second

### Requirement: Capture supported content types
The system SHALL capture plain text, rich text (RTF and HTML) and images (PNG, TIFF) from the clipboard, preserving all available representations of the same copy as one entry.

#### Scenario: Rich text copied
- **WHEN** the user copies formatted text that offers plain, RTF and HTML representations
- **THEN** one entry is recorded that retains all three representations

#### Scenario: Image copied
- **WHEN** the user copies an image (for example a screenshot to clipboard)
- **THEN** one image entry is recorded

### Requirement: Ignore sensitive clipboard data
The system SHALL NOT record clipboard items marked as concealed, transient or auto-generated (org.nspasteboard.ConcealedType, TransientType, AutoGeneratedType), nor items copied while an app on the exclusion list is frontmost.

#### Scenario: Password manager copy
- **WHEN** a password manager places a concealed item on the clipboard
- **THEN** no history entry is created

#### Scenario: Excluded application
- **WHEN** the frontmost app's bundle identifier is on the exclusion list and the user copies text
- **THEN** no history entry is created

### Requirement: Ignore own clipboard writes
The system SHALL NOT record clipboard changes that it made itself when pasting a history entry.

#### Scenario: Re-paste from history
- **WHEN** the user selects an entry from the panel
- **THEN** the clipboard write performed by MacClip does not create a new entry or change ordering twice

### Requirement: Pause capture
The system SHALL let the user pause and resume capturing from the menu-bar menu, and SHALL record nothing while paused.

#### Scenario: Paused
- **WHEN** capture is paused and the user copies text
- **THEN** no entry is created until capture is resumed

### Requirement: Skip oversized items
The system SHALL skip text larger than 1 MB and images larger than 25 MB, and SHALL log the skip without crashing.

#### Scenario: Huge image
- **WHEN** the user copies an image larger than 25 MB
- **THEN** it is not stored and the app keeps running
